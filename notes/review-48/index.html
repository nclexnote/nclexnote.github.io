요약노트 · 빈출 개념

빈출 개념 3가지: 갑상선 약·진실성·교액성 탈장

자주 헷갈리는 빈출 개념 세 가지를 쇼츠 3개로 한 번에 복습해요. 세 주제의 공통 원리는 하나예요 — "그럴듯해 보여도 한 번 더 확인하고, 사실대로, 급한 건 바로": 처방은 질환과 맞는 약인지, 가족의 부탁은 환자의 알 권리와 맞는지, 탈장은 다시 들어가는지를 확인해요.

블로그 글을 한 장으로 줄인 요약노트 · 직접 정리

갑상선 저하증에 거를 약

가려진 칸을 누르면 답이 보여요.

  • 갑상선 기능 저하증에 쓰는 약은?레보티록신(levothyroxine)이에요. 부족한 호르몬을 채우는 약이에요.
  • 메티마졸·PTU는 어디에 쓰나요?기능 항진증이에요. 호르몬 생산을 막는 약이에요.
  • 저하증 환자 처방에 메티마졸이 있으면?질환과 반대인 약이에요. 보류 → 처방자에게 확인 → 기록이에요.
  • 레보티록신 복용 교육은?아침 공복에 물과 함께(식사 30~60분 전), 칼슘·철분·제산제와는 4시간 간격, 평생 복용이에요.
  • 레보티록신이 넘친다는 신호는?가슴 두근거림, 빠른 맥박, 흉통, 더위를 못 참음, 체중 감소, 불면이에요.
  • 메티마졸을 쓰는 환자가 바로 보고할 증상은?열과 목 아픔이에요. 백혈구 감소 신호예요.

진실성(Veracity)

  • 진실성(veracity)이란?환자에게 진실을 말할 의무예요.
  • 가족이 "말하지 말아 주세요" 하면?거짓말하거나 숨기겠다고 약속하지 않아요. 가족의 걱정을 먼저 듣고, 처방자·치료팀에 알려요.
  • 진단 설명은 누구의 역할인가요?처방자의 역할이에요. 간호사가 혼자 진단을 알리지 않아요.
  • 환자가 얼마나 알고 싶어 하는지는 누구에게 묻나요?환자에게 직접 물어요. 가족이 대신 정하는 게 아니에요.
  • 신의(fidelity)와 진실성(veracity)의 차이는?신의는 약속 지키기, 진실성은 사실대로 말하기예요.

교액성 탈장

  • 급하지 않은 탈장의 모습은?누우면 들어가고, 기침하거나 무거운 것을 들 때 불룩해져요. 예약 진료로 충분해요.
  • 감돈과 교액의 차이는?끼어서 안 들어가는 상태가 감돈(incarcerated), 거기서 혈류까지 막힌 상태가 교액(strangulated)이에요.
  • 교액성 탈장의 신호는?심한 통증·압통, 피부색 변화, 구역·구토, 열, 가스·대변이 안 나옴이에요.
  • 교액이 의심될 때 간호는?금식(NPO), 즉시 보고, 응급 수술 준비예요. 억지로 밀어 넣지 않아요.
  • 수술 뒤 교육은?무거운 것 들기·힘주기 피하기, 기침할 때 상처 받치기, 음낭이 부으면 지지대와 얼음, 소변을 못 보면 보고예요.
