체위

체위 문제는 "이름 → 침대 모양 → 왜 그 자세인지" 세 가지만 연결하면 풀려요. 파울러는 등판을 올리는 각도로(낮은 15~30도 · 반좌위 30~45도 · 표준 45~60도 · 높은 60~90도), 트렌델렌버그는 침대 전체를 기울이는 방향으로 나뉘어요. 숨이 차면 올리고, 뇌압이 높으면 30도, 찌른 자리는 눌리게, 탯줄과 태반은 눌리지 않게 — 이유를 알면 외울 게 줄어요. 🖼 여기에 그림 넣기: 20261110_엔클렉스_체위8가지_그림.png (폭 본문 가득·가운데 정렬 · 직접 그린 그림이라 "AI로 만든 그림" 표시는 넣지 않아요)

눌러서 확인하기

앞부분을 보고 뒷부분을 떠올려 보세요.

  • 파울러 각도낮은 15~30 · 반좌위 30~45 · 표준 45~60 · 높은 60~90(등판만 올림) / 트렌델렌버그 = 침대 전체를 기울여 머리 낮게
  • 호흡곤란·비위관 삽입높은 파울러 / 경관영양 = 30~45도 / 뇌압 상승 = 30도 + 목 중립, 머리 낮추기 금지
  • 간 생검 뒤오른쪽 측위 / 요추천자 = 할 땐 새우 자세, 뒤엔 평평하게
  • 공기 색전왼쪽 측위 + 머리 낮게 / 제대 탈출 = 무릎-가슴 자세 / 후기 감속 = 왼쪽 측위
  • 자율신경 반사부전먼저 앉히기 / 절단 뒤 = 복위로 구축 예방 / 관장 = 왼쪽 측위
