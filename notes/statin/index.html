스타틴 종류

스타틴은 이름 끝이 -statin인 콜레스테롤(LDL) 낮추는 약이에요. 간호사가 꼭 기억할 건 하나 — 환자가 이유 없는 근육통·힘 빠짐·콜라색 소변을 말하면 그냥 넘기지 말고 다음 약을 보류하고 바로 보고해요(횡문근융해 의심, CK 확인). 여기에 복용 시간(심바스타틴은 저녁), 자몽주스, 간 증상, 임신이면 중단까지 묶어서 외워요.

눌러서 확인하기

앞부분을 보고 뒷부분을 떠올려 보세요.

  • -statinHMG-CoA 환원효소 억제 → LDL↓, 목적은 심근경색·뇌졸중 예방
  • 근육통·압통·힘 빠짐보류·보고·CK / 콜라색 소변 → 횡문근융해, 즉시 보고·소변량·신장 수치
  • 위험 요인65세 이상·갑상선 저하·신장 기능 저하·고용량·병용약
  • 심바스타틴·로바스타틴저녁(로바스타틴은 저녁 식사와), 아토르바·로수바 = 아무 때나 같은 시간
  • 자몽주스 피하기, 젬피브로질·니아신·마크롤라이드·아졸 병용근육 위험↑
  • 간수치시작 전 + 필요할 때, 간 증상(피로·식욕↓·윗배 통증·진한 소변·황달) 보고, 술 줄이기
  • 임신이면 알리고 대부분 중단수유 ✖
  • 수치가 좋아져도 계속 복용식단·운동 함께, 4~12주 뒤 지질 검사

암기 팁

  • 스타틴 교육은 "근·저·자·간·임" — 근육통은 보고, 저녁에 먹고(심바·로바), 자몽주스는 피하고, 간 증상 보고, 임신이면 중단!
  • "콜라색 소변 = 근육이 녹은 색" — 근육통 + 콜라색 소변이면 횡문근융해, CK 확인.
