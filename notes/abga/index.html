ABGA 해석: 네 걸음으로 읽기

pH → PaCO₂ → HCO₃⁻ → 보상 순서로 읽으면 풀려요. CO₂는 산, HCO₃⁻는 염기예요.

확인 2026-11-13 · Saunders 9판 표 9.3 기준 · 직접 정리

한 줄 핵심

pH와 PaCO₂가 반대로 움직이면 호흡성, pH와 HCO₃⁻가 같은 쪽으로 움직이면 대사성이에요. 줄여서 ROME(Respiratory Opposite, Metabolic Equal)이에요.

정상 수치

가려진 칸을 누르면 답이 보여요.

항목정상 범위뜻
pH7.35~7.45낮으면 산증, 높으면 알칼리증
PaCO₂35~45 mmHg폐가 조절해요. 높으면 산 쪽
HCO₃⁻21~28 mEq/L신장이 조절하는 염기예요. 높으면 알칼리 쪽
PaO₂80~100 mmHg산소 상태만 알려 줘요. 산증·알칼리증을 가르는 데는 쓰지 않아요

HCO₃⁻는 교재마다 조금 달라요. Saunders 9판은 21~28, 다른 자료와 검사실은 22~26을 쓰기도 해요. 공부하는 교재의 숫자로 외우면 돼요.

읽는 순서 네 걸음

  1. pH: 산증인지 알칼리증인지 먼저 정해요.
  2. PaCO₂: pH와 반대 방향으로 움직였으면 호흡성이에요.
  3. HCO₃⁻: pH와 같은 방향으로 움직였으면 대사성이에요.
  4. 보상: 원인이 아닌 반대쪽 값이 정상인지, 움직였는지 봐요.

네 가지 불균형

구분pH먼저 변하는 값흔한 원인간호 핵심
호흡성 산증낮음PaCO₂ 높음COPD, 진정제, 폐렴기도·환기 먼저
호흡성 알칼리증높음PaCO₂ 낮음불안, 통증, 발열원인·산소 확인
대사성 산증낮음HCO₃⁻ 낮음DKA, 설사, 신부전원인 치료·칼륨
대사성 알칼리증높음HCO₃⁻ 높음구토, 위 흡인, 이뇨제수분·칼륨 보충

보상 구분

구분pH반대쪽 값뜻
비보상정상 밖정상아직 돕지 못함
부분 보상정상 밖정상 밖돕는 중
완전 보상정상 안정상 밖다 따라잡음

완전 보상이면 7.40을 기준으로 봐요. 7.40보다 낮으면 원래 문제는 산증, 높으면 알칼리증이에요. 폐는 몇 분에서 몇 시간 안에 빠르게 돕고, 신장은 며칠에 걸쳐 천천히 도와요.

정답 보기
  1. 비보상 호흡성 산증: pH 낮음 → PaCO₂ 높음(반대 방향) → HCO₃⁻ 정상
  2. 부분 보상 대사성 산증: pH 낮음 → HCO₃⁻ 낮음(같은 방향) → PaCO₂도 낮음, pH는 아직 정상 밖
  3. 비보상 호흡성 알칼리증: pH 높음 → PaCO₂ 낮음(반대 방향) → HCO₃⁻ 정상
  4. 비보상 대사성 알칼리증: pH 높음 → HCO₃⁻ 높음(같은 방향) → PaCO₂ 정상
  5. 완전 보상 호흡성 산증: pH 정상이지만 7.40보다 낮음 → PaCO₂ 높음(원인) → HCO₃⁻ 높음

시험용 기본 분류예요. 실제 임상에서는 예상 보상 범위와 병이 시작된 때까지 함께 봐요.

여기서 많이 틀려요

  1. CO₂를 염기로 착각해요. CO₂는 산이에요.
  2. 구토와 설사를 바꿔 외워요. 구토는 위산을 잃어 알칼리증, 설사는 염기를 잃어 산증이에요.
  3. pH가 정상이면 "정상"이라고 답해요. PaCO₂와 HCO₃⁻가 둘 다 정상 밖이면 완전 보상이에요.
  4. 쿠스마울 호흡을 호흡기 문제로 봐요. 대사성 산증을 폐가 돕는 보상 호흡이에요.
  5. PaO₂로 산증·알칼리증을 가르려고 해요. PaO₂는 산소 상태만 알려 줘요.

함께 기억할 것

  • 산증이면 칼륨이 올라가기 쉽고, 알칼리증이면 내려가기 쉬워요. 칼륨 수치와 심전도를 같이 봐요.
  • CO₂가 쌓일 위험이 있는 COPD 환자는 보통 산소포화도 88~92%를 목표로 조절해요. 필요한 산소를 아끼라는 뜻은 아니에요.
  • DKA에서 중탄산염은 일상적으로 쓰지 않아요. 수액·인슐린·칼륨 관리가 먼저예요.
  • 어떤 불균형이든 의식과 호흡을 먼저 살펴요.
