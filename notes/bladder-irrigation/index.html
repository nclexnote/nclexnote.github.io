지속 방광 세척 CBI 간호 정리

전립선 절제술(TURP) 뒤에는 혈괴로 관이 막히지 않게 3-way 도뇨관으로 생리식염수를 계속 흘려요. 시험에서 묻는 건 하나 — 배액이 줄고 아랫배가 팽만·통증이면 "막힘"이니 속도를 올리지 말고, 세척액을 잠그고 관부터 확인·보고. 그리고 실제 소변량 = 총 배액 − 넣은 세척액.

눌러서 확인하기

앞부분을 보고 뒷부분을 떠올려 보세요.

  • 배액↓ + 팽만·통증막힘 → 세척 잠그기 → 꼬임·혈괴 확인 → 손 세척(처방) → 보고, 속도 올리기 ✖
  • 실제 소변량배액 − 세척액
  • 선홍·혈괴↑ → 속도↑ / 연분홍정상
  • 방광 경련힘주지 않기, 개방 확인 뒤 진경제
  • 남성 삽입 90°·갈림까지주머니 방광 아래·바닥 ✖, 가장 작은 크기, 매일 필요성 평가
