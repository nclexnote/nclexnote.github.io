처방 확인

간호사는 처방을 그대로 실행하는 사람이 아니라 마지막 안전장치예요. 처방이 이상하면 보류 → 처방자에게 직접 확인 → 기록(보·확·기). 거를 처방은 ① 보통 용량을 크게 넘는 양, ② 진단과 반대인 약, ③ 금기(알레르기·질환) 세 가지이고, 확인했는데 "그대로 주라"고 해도 해롭다고 판단되면 거부하고 위로 보고해요.

눌러서 확인하기

앞부분을 보고 뒷부분을 떠올려 보세요.

  • 이상한 처방보류 → 처방자 직접 확인 → 기록(보·확·기)
  • 거를 셋열 배 용량 · 진단과 반대 약 · 금기(알레르기·천식에 비선택적 베타차단제)
  • 저하증에 메티마졸, 요붕증에 리튬반대 약
  • 용량 임의 변경 ✖약사에게 대체 요청 ✖, 알면서 투약 ✖
  • 구두 처방응급 때만, 적고 다시 읽기, 서명 / "그대로 주라"도 해로우면 거부 + 지휘 체계 + 기록
